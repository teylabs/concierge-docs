# Concierge Documentation

Source for the documentation site of [tey/concierge](https://github.com/teylabs/concierge), published at [concierge.teylabs.com](https://concierge.teylabs.com).

The site is built with [VitePress](https://vitepress.dev). Pages live in `docs/`, and every push to `main` deploys the site through GitHub Pages.

```bash
npm ci
npm run dev     # http://localhost:5173
npm run build   # checks the footer credit line, llms.txt, llms-full.txt and styling, then builds .vitepress/dist
npm run preview # http://localhost:5299
```

Styling goes through `.vitepress/theme/custom.css` and VitePress's CSS variables only; `scripts/styling.test.mjs` fails the build on any other stylesheet, `<style>` block or `style=` attribute. See [AGENTS.md](AGENTS.md).

The build also publishes, for coding agents, [`/llms.txt`](https://concierge.teylabs.com/llms.txt) (an index), [`/llms-full.txt`](https://concierge.teylabs.com/llms-full.txt) (every sidebar page in order, as one Markdown file) and the Markdown source of every page beside its HTML. The build fails if a sidebar page is missing from either file.

The brand kit (mark, favicons, banners and share card) is generated by `brand/build.mjs`, which also copies the site's icons, logos and share card into `docs/public/`; see [brand/README.md](brand/README.md).
